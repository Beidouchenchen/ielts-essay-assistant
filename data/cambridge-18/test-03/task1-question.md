# Writing Task 1 Question

**Source:** Cambridge IELTS 18, Test 3

## Prompt

The diagrams below show the layout of Central Library before and after changes were made to it.

Summarise the information by selecting and reporting the main features, and make comparisons where relevant.

Write at least 150 words.

## Data

### Central Library Layout - Before Changes

| Location | Feature |
|----------|---------|
| Left of entrance | Reading room (newspapers, magazines) |
| Right of entrance | Enquiry desk |
| Left side | Reference books |
| Right side | Adult fiction |
| Back left corner | Computer games, CDs, videos |
| Back right corner | Children's books |
| Centre | Adult non-fiction |

### Central Library Layout - After Changes

| Location | Feature |
|----------|---------|
| Left of entrance | Computer room |
| Right of entrance | Café |
| Left side | Reference books |
| Right side | Adult fiction |
| Back left corner | Children's fiction (enlarged) + storytelling space |
| Back right corner | Lecture room |
| Centre | Smaller information desk + self-service machines |

## Key Visual Features

- **Map comparison** (before and after, 20-year period)
- Reading room → Computer room
- Enquiry desk → Café
- Added: self-service machines, lecture room, storytelling space
- Children's section enlarged
